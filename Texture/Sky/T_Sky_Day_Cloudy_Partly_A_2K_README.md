# T_Sky_Day_Cloudy_Partly_A_2K

Generated low-poly/blockout style sky panorama for spherical sky domes.

- Projection: equirectangular / latitude-longitude
- Coverage: 360 degrees horizontal, 180 degrees vertical
- Dimensions: 4096x2048, exact 2:1 aspect ratio
- Format: 16-bit RGB PNG, no alpha
- Orientation: top edge zenith, center horizontal line horizon, bottom edge nadir
- Seam: left and right columns are identical for seamless repeat wrapping

Run `python T_Sky_Day_Cloudy_Partly_A_2K_generate.py` from this directory to regenerate the PNG.
